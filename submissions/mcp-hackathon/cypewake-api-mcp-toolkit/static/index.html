Tool Curation

Fixes the 100-endpoints-to-100-tools blowup that floods the agent context window. Filter by tag, method, path, or intent before generating. Leave empty to export everything.
Example: {"intent":"user order","top_n":5} takes the 5 most relevant operations by semantics; {"include_path_patterns":["/pet/*"],"exclude_methods":["DELETE"]} keeps only non-DELETE operations under /pet.
Defaults to the public keyless Swagger Petstore. Swap in any OpenAPI/Swagger URL, local file path, or pasted text.

BUILDParse and extract

Reads the spec: expands $ref, merges path-level parameters, detects auth schemes and pagination, and emits an operation list with JSON Schema.

VERIFYReal verification

Calls every endpoint for real, concurrently. Only HTTP 2xx counts as a pass; 401/403 means auth required, other 4xx means bad parameters, network failure means unreachable.

MCPIZEGenerate deployable bundle

Turns the whole spec into a deployable MCP server package (server.py + dependencies + README + manifest). What lands on disk is the finished artifact.

MONETIZEMeter and bill

Builds the listing payload (per-tool schema plus pricing tiers) and bills from real metered calls — not a hand-waved price table.

Usage and invoices

Metered on every real call through this service (usage.json).
