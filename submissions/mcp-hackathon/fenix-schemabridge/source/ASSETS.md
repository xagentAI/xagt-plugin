# Visual assets

## Illustration

`public/assets/schema-sculpture.png` is the original light bridge illustration selected by the project owner. It was created for SchemaBridge with the built-in OpenAI image-generation tool. The tool did not expose its exact model identifier; this project does not claim a particular generation model version.

The illustration represents loose records becoming an ordered schema. It is illustrative artwork, not a screenshot or a claim about software output. It is displayed without a color filter or a replacement dark treatment.
