### P1 · 过审后 7–14 天 · 「用钱投票」

| # | 动作 | 完成定义 |
|---|---|---|
| 1 | 只观测、少改产品 | 记录：每条 path 的有机付费次数（平台 sold / 自有日志若有） |
| 2 | 锁主线 | **付费最多的 1–2 条 path = 商业主线**；演示叙事可保留决策卡 |
| 3 | 加深主线 | 只加深有付费的；无付费的停止讲故事 |
| 4 | Kill | 有曝光仍持续 0 付费的 SKU → 降维护，不加功能自证 |
| 5 | pnl-audit | 仅当「验证钱包成绩单」方向出现付费信号或你下令 → 再开工 |

### P2 · 主线有复购之后 · 「护城河」

- PolyData / OSS 加深主线信号质量  
- 同 API 多通道（降低单平台风险）  
- 订阅/额度仅在 L1 复购成立后
