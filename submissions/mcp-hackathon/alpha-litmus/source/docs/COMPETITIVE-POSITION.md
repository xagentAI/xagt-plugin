# AlphaLitmus Position

AlphaLitmus is a bounded strategy failure-testing and evidence-reconciliation tool for agents. Its useful output is an inspectable reason to reject or withhold a claim, a tested failure boundary, or a narrowly scoped survival report. It is not a profit predictor, execution bot or security-audit service.

| Alternative category | AlphaLitmus distinction | Honest limitation |
| --- | --- | --- |
| Summary backtest dashboard | Explicit eligibility, failure observations and unavailable tests | Daily spot reference only; no general strategy runtime |
| Simple Nexus wrapper | Conditional arithmetic across four surfaces and explicit missing evidence | No complete-history attestation or bound-strategy replay |
| Narrative agent analysis | Machine-readable bounded experiments and deterministic offline verification | Inputs and strategy selection can still be fabricated or biased |
| Full quantitative research platform | Small, inspectable fixed model with documented costs and domains | No portfolio optimizer, intraday simulator, capacity model or broad asset support |
| Signed provenance service | Content-addressed reports with replay checking | Checksums are not signatures, authorship or source authenticity |

This comparison describes product categories, not a benchmark of named competitors. No market share, customer adoption, performance superiority, uniqueness, rights ownership or award likelihood is asserted. The project has no supplied deployed-service evidence or independently verified Nexus strategy edge.

The current official scorecard favors real utility, demonstrated capability, engineering, MCP readiness and operation. A credible demonstration should show a negative result, a missing-evidence case, a detected tamper, and the exact limits of a successful verification. It should not hide unsuccessful experiments or substitute a polished UI for deployment and source evidence.
