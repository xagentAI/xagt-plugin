## Other components

- The Go installer module in `source/packaging/linux/installer/go.mod` has no third-party module requirements; Go and its standard library are build/runtime dependencies supplied separately.
- Solidity configuration is in `source/contracts/foundry.toml`. Source SPDX headers are preserved. Foundry is external test/build tooling, not bundled here.
- Docker base-image and operating-system components are installed separately during the build, not redistributed as source in this submission. Their upstream terms remain applicable.
- The original Clink-derived first-party code requires the submitter's authority to submit it; this inventory cannot establish that ownership.

## Scope of authorization

The proposed official review/archive authorization appears in RIGHTS.md. It does not relicense third-party software, change existing notices, or assert a blanket open-source license for first-party code. No runtime credentials or customer datasets are included. Automated metadata collection and secret scans are not exhaustive license or privacy certifications.
