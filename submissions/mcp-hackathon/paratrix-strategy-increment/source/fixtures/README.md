# Example data and provenance

## Recorded AIMM runs

`recorded/aimm/` contains three equity records generated by local backtests using a pinned AIMM version, with 60 JSONL rows each. The upstream revision, run configuration, initial capital, dates, and SHA-256 hashes are in [manifest.json](recorded/aimm/manifest.json). Original file bytes are preserved; the adapter checks hashes and point counts on every read, including the embedded-byte copies in Worker bundles.

The market-price input was the upstream repository's daily BTC/USDT CSV; its hash is recorded in the manifest. This repository contains equity outputs and a research summary. The example demonstrates simulated research over an already-observed interval; the price source has not been independently certified as market data. See the [third-party inventory](../third-party/README.md) for the upstream license.

The first JSONL row is equity after the first evaluated bar. The adapter reads the initial 10,000 USDT from the manifest and converts original bar-open labels to end-of-day valuation boundaries, producing 61 valuation points and 60 daily returns. See `app/adapters/demos.py` for the implementation. Run provenance is in the [AIMM record](../docs/evidence/aimm-feasibility-evidence.json). A retained [reproducible experiment](../../verification/local-evidence.json) contains complete inputs, all 61 valuations, rules, and results from its recorded application version.

## Teaching examples

`app/adapters/demos.py` generates examples deterministically:

| Example | Construction | Purpose |
| --- | --- | --- |
| `aimm-weight` | Read the AIMM baseline and weight variant | Compare two recorded simulated results |
| `duplicate` | Copy the AIMM baseline into the candidate | Verify that AB equals A |
| `cash` | Keep the baseline and make the candidate constant | Verify that AB equals the cash control |
| `missing-day` | Remove one day from the AIMM candidate | Verify rejection of missing data |
| `tradeoff` | Generate two constructed curves | Show drawdown improvement and return sacrifice |

Source labels and observed-data declarations are retained in snapshots, experiments, and exported evidence. `synthetic/` identifies where constructed examples are implemented; their curves are generated at runtime.
