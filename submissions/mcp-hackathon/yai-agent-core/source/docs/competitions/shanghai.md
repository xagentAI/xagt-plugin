# 2026 上海开源软件应用创新大赛 提交清单

- 官网：https://www.oschina.net/os2026/
- 时间：报名+提交至 10.11 24:00（邮件 oscc@oschina.cn）；入围公布 10.16；决赛 10.24 张江科学会堂

## 选赛道

首选 **智算云赛道（智能体框架/运行时方向）**；备选开源 AI 工具赛道（AI 开发工具）。

## 评审维度对应

| 维度 | 权重 | YAI 动作 |
|---|---|---|
| 技术创新 | 30% | 能力自发现+策略自适应；README 放与 5 类现有方案的诚实对比表 |
| 场景落地 | 30% | 双宿主 demo + 在线 API + 录屏，可部署可运行可测试 |
| 开源治理 | 20% | MIT LICENSE、README/CONTRIBUTING、GitHub Actions(CI)、pytest、Issue/PR 模板、规范 commit |
| 长期发展 | 20% | AMBRACE 回流路线图、版本路线、社区文档 |

## 提交材料

1. 代码仓库链接（公开、完整可运行）
2. 作品介绍 PDF（背景/技术架构/应用场景/创新点）
3. 演示视频链接（核心功能与使用流程）
4. 个人/团队均可，建议 3–5 人；每项目限一个赛道
