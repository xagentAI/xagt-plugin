# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-17

### Added

- Deterministic opportunity-domain and innovation-type classification.
- Advisory-only validation routing with all execution and capital authority disabled.
- Health, deployment-proof, OpenAPI, and profile endpoints.
- Closed request and response schemas.
- Request-size, JSON-depth, timeout, concurrency, and field-length limits.
- Restrictive HTTP headers and default-disabled request logging.
- Version-and-digest-pinned non-root Docker image.
- English and Chinese documentation, security policy, and public-source allowlist.
